# Infer album membership from retained import evidence

External catalogs do not cover every owned release, so Syncstr accepts directory context together with album tags and explicit compilation or disc evidence as grounds for automatic membership, while preserving explicit listener choices and contradictory edition evidence. Retain this import context with the shared catalog, independently of current file locations, so replication and source unavailability do not destroy the basis of an album's organization. This accepts bounded inference and the cost of preserving its provenance instead of requiring an external release identifier or repeated manual grouping; the exact boundaries and artwork policy are agreed in the [compilation policy review](../compilation-policy-review.md), with conflicts governed by the [cluster model](../cluster-model-design.md).

This is an accepted design decision; the revised behavior is not yet implemented.
