# Audio Fixtures

`untagged.mp3`, `untagged.flac`, and `untagged.m4a` are 440 Hz, 0.1-second sine waves generated with ffmpeg 9.0.1. They contain no purchased audio.

```sh
ffmpeg -f lavfi -i 'sine=frequency=440:duration=0.1' -map_metadata -1 -y untagged.flac
```

The other formats were generated by changing only the output extension.
